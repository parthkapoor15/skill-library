# Skill Library

Parth's curated shelf of Claude skills — and the scout that keeps it honest.

Thousands of skills get published. Most are a prompt in a trench coat. This repo
exists to catch the few that would actually change how work gets done, and to say
no to the rest with a reason.

## How it works

Every day a scheduled Claude run:

1. Reads `SCOUT.md` (the playbook — edit it to change what the scout cares about).
2. Sweeps the sources listed there for skills published or updated since the last run.
3. Skips anything already in `reviews.json`, and walks the towers: opens the next 15 unopened skills in the catalogue.
4. Reads each candidate's `SKILL.md` and any scripts, checks it for safety, and scores it.
5. Logs every verdict in `reviews.json`, rebuilds `REVIEWS.md`, and refreshes the dashboard.
6. Picks at most one standout ADD, adopts it into `skills/` and builds its zip — queued for you to approve with "install <name>".
7. Commits and pushes.

Verdicts are **ADD**, **WATCH**, or **SKIP**. Only ADD and WATCH get a full write-up;
SKIPs get one line so you can see the scout isn't sleeping.

## Layout

| Path | What it is |
|---|---|
| `SCOUT.md` | The scout's playbook: sources, rubric, safety gate, report format |
| `reviews.json` | The ledger: every skill ever reviewed, with scores — the single source of truth |
| `REVIEWS.md` | Readable verdicts, newest first (generated by `tools/render.py`) |
| `tools/render.py` | Rebuilds `REVIEWS.md` from the ledger |
| `tools/package.py` | Zips an adopted skill for upload to Claude |
| `dist/` | Ready-to-upload skill zips |
| `skills/` | Skills you've decided to keep — one folder per skill |

## Adding a skill you liked

Tell Claude "add `<skill name>`" — it copies the skill into `skills/<name>/` with a
`SOURCE.md` (origin, licence, commit), sets `adopted` on its entry in `reviews.json`,
and builds upload zips with `python3 tools/package.py <name>` into `dist/`.
Install: Settings → Capabilities → code execution on; then Customize → Skills →
**+** → Create skill → Upload a skill.

Adopted so far: **Hairline** (`skills/hairline/`).

## Changing the bar

Edit the **Lanes** and **Rubric** sections of `SCOUT.md`. The next run uses it.
